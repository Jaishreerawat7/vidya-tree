# Vidya Tree

A friendly learning app for young children, presented by Chiku the owl. It covers Maths, Science, English, Hindi, Sanskrit and Rig Veda, following the Cambridge Primary, CBSE (NCERT) and England National Curriculum paths.

**Open it:** https://jaishreerawat7.github.io/vidya-tree/

## Put it on an iPad
1. Open the link above in **Safari**.
2. Tap the **Share** button, then **Add to Home Screen**, then **Add**.
3. Open it from the Vidya Tree icon. It runs full-screen and keeps working offline once it has loaded.

## Notes
- Progress, stickers and drawings stay on the device. Use Grown-ups → "Save a backup" to keep a copy.
- Live chat with Chiku runs in the Claude version (button inside the app).
- Voices: "Jenny (Dioco)" English voice and "Priyamvada" Hindi voice (Piper, CC BY-NC-SA, non-commercial). Photos: NASA (public domain) and CC0 sources.
